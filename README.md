# WeMed (PWA): запуск за ~20 минут

В папке готовое приложение. Нужно сделать три вещи: завести бесплатную облачную базу, вписать два ключа и выложить папку на хостинг.

## Шаг 1. База и вход (Supabase)

1. Зарегистрируйтесь на https://supabase.com и создайте проект (New project). Запомните пароль базы, он нужен только вам.
2. Откройте **SQL Editor → New query**, вставьте весь файл `supabase.sql` и нажмите **Run**. Создадутся таблицы с защитой: каждый видит только свои данные.
3. Откройте **Project Settings → API** и скопируйте:
   - **Project URL**
   - **anon public key** (публичный ключ; его можно держать в коде. Ключ `service_role` никому не показывайте и в код не вставляйте).
4. Откройте файл `config.js` и вставьте эти два значения между кавычками.
5. **Authentication → Providers → Email**: вход по почте включён по умолчанию. Для быстрых тестов можно отключить «Confirm email», а для реального запуска лучше оставить включённым, чтобы почту подтверждали.
6. **Authentication → URL Configuration**: в «Site URL» впишите адрес вашего сайта (получите на шаге 2) и добавьте его же в «Redirect URLs». Это нужно для ссылки «Забыли пароль».

## Шаг 2. Хостинг (самый простой вариант: Netlify)

1. Зайдите на https://app.netlify.com/drop (нужна бесплатная регистрация).
2. Перетащите в окно **всю папку** с этими файлами. Через минуту появится адрес вида `https://что-то.netlify.app`.
3. Вернитесь в Supabase (шаг 1.6) и впишите этот адрес.
4. Позже можно подключить свой домен (Site configuration → Domain management).

Подойдёт и Cloudflare Pages, и GitHub Pages: нужно просто выложить эти файлы как статический сайт.

## Шаг 3. Проверка

1. Откройте адрес на телефоне, нажмите значок человека вверху → «Регистрация».
2. Добавьте задачу, затем откройте сайт на другом устройстве и войдите тем же аккаунтом. Задача должна появиться.
3. Установка: Android: меню браузера → «Установить приложение»; iPhone (Safari): «Поделиться» → «На экран Домой».

## Как это устроено

- Данные пользователя лежат в одной записи таблицы `user_data` (JSON). Приложение работает и без интернета, а изменения уходят в облако, когда связь появится.
- При работе на двух устройствах изменения объединяются (записи сливаются по id, удаления учитываются).
- При выходе из аккаунта копия на устройстве очищается.
- Заготовка таблицы `subscriptions` уже создана для будущих платных подписок.

## Что пока не сделано

- Оплата и подписки (следующий этап).
- Push-напоминания, вход через Telegram/Google, удаление аккаунта самим пользователем.
- Политика конфиденциальности и оферта (нужны до публичного запуска). Если будете хранить данные граждан РФ, проверьте требования к расположению серверов.
